# UI/UX Swiss Knife

Chrome-расширение для проверки сайта “на цифрах”: расстояние A-B в пикселях, пипетка цвета и извлечение DOM-имен блока по клику.

## Как установить

### Через папку

1. Откройте `chrome://extensions`.
2. Включите Developer mode.
3. Нажмите Load unpacked.
4. Выберите корневую папку этого репозитория.
5. Откройте любой сайт и нажмите иконку UI/UX Swiss Knife на панели Chrome.

### Через архив

Соберите архив:

```bash
npm run pack:extension
```

Готовый zip появится в `dist/`. Внутри него `manifest.json` лежит в корне архива.

## Что умеет

- **A-B**: зажмите ЛКМ в точке A, протяните линию до точки B и отпустите. Расширение покажет расстояние в CSS-пикселях, `dx` и `dy`.
- **Выравнивание**: кнопка притягивает линию к шагу 45 градусов. Выключите ее, если нужно свободно провести линию от угла к углу.
- **Цвет**: режим пипетки делает внутренний снимок видимой области вкладки. Наведите лупу на пиксель и кликните ЛКМ: цвет фиксируется, появляется меню `HEX`, `RGB`, `RGBA`, `HSL`, `CSS`. Нажмите нужную строку, чтобы скопировать.
- **Имена**: наведите на элемент и кликните. Расширение показывает копируемые строки `id`, `class`, `data-*`, `aria-label`, `name`, `role`, CSS selector и best-effort имена React/Vue/Angular компонентов, если сайт их раскрывает в DOM/dev hooks.
- **Шрифт**: наведите на текстовый блок и кликните. Расширение показывает font-family, size, line-height, weight, style, letter-spacing, transform, color, stretch, variation/features, align, decoration и готовый CSS `font` shorthand. Любая строка копируется кликом.
- **Esc**: скрывает инструмент с экрана. Повторный клик по иконке расширения вернет панель.
- **Размер панели**: потяните ручку `↙` внизу слева, чтобы расширить интерфейс влево и вниз.

## Ограничения

- Пипетка читает только видимую область вкладки на момент внутреннего снимка. После прокрутки, анимаций или изменения страницы нажмите “Обновить”.
- Расширение не может гарантированно узнать имя переменной из исходного кода сайта. Оно извлекает то, что реально доступно в DOM: классы вроде `hero-h1`, id, data-атрибуты и framework hints.
- На `chrome://` страницах и локальных `file://` страницах Chrome может требовать дополнительные разрешения.

## CI/CD и релизы

GitHub Actions проверяет каждый push в `main` и каждый pull request: запускает синтаксическую проверку, тесты, собирает zip расширения и сохраняет его как artifact.

Релиз создается пушем git-тега:

```bash
git tag v0.3.0
git push origin v0.3.0
```

Release workflow повторно запускает проверки, собирает zip, создает GitHub Release и прикладывает архив из `dist/`. Changelog генерируется из сообщений коммитов между предыдущим тегом и новым тегом.

## Проверка

Внутри папки расширения можно запустить:

```bash
npm run check
npm test
```

Для ручной проверки откройте `demo/test-page.html` в браузере и включите расширение. На странице есть блоки с именами `hero`, `hero-h1`, `feature-card`, `cta-button` и отдельный шрифтовой пример.
